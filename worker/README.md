# ShortsFire worker

`worker.js` = the whole backend: feed algorithm, store (LayerBase libSQL), caps/prune, and the collector.
The collector now uses **YouTube InnerTube** (no API key) and runs **every 30 minutes** via Cloudflare cron.
Shorts are stored in your database; when someone opens the site, the feed comes from the DB and plays as YouTube embeds.

## Deploy
```bash
cd worker
npx wrangler secret put TURSO_AUTH_TOKEN     # LayerBase libSQL token
npx wrangler secret put CRON_SECRET          # any long random string
# TURSO_DATABASE_URL = https://<host>.cloud.layerbase.dev  -> set in wrangler.toml [vars] or the dashboard
npx wrangler deploy
```
`wrangler.toml` has `crons = ["*/30 * * * *"]`. Collect runs on each tick (gap 25 min), 3 InnerTube searches per tick, one category per search, rotating.

Check it works: `curl -X POST "https://<worker>/api/collect?secret=<CRON_SECRET>"`, then `https://<worker>/api/feed?userId=me&mood=focus`.

## The page (`index.html`)
`index.html` is the worker's own player (generated by `node worker/build-index.mjs`). Two ways to open it:
1. **Open the worker URL** `https://<worker>/`. Same origin, no config.
2. **GitHub Pages**: set `window.SF_API_BASE = 'https://<worker>.workers.dev'` at the top of `index.html`
   (rerun `build-index.mjs` after editing the constant there, or edit the line directly). CORS is enabled on the worker.

## Not configured (by design)
- Telegram storage and the YouTube grab routes (`TG_BOT_TOKEN`, `TG_CHAT_ID`, cookies) are unset.
  Without them nothing is downloaded from YouTube; playback is the YouTube embed.

## Tests
`node worker/test/smoke.mjs`: runs the real worker against a local libSQL pipeline server. The InnerTube
response is mocked, so it checks: collect -> DB store -> feed serve, Shorts-only filter, CORS, signals, stats, and the cron handler.
